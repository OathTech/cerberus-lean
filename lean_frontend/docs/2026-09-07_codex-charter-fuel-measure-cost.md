## 2. Deliverables — ordered; one at a time; each ends with a gate and a commit

### D1 — Per-row CPU instrument and the HEAD baseline measurement

It must reuse the lane's own staging (`CSMITH_MINIMAL` header substitution, `sa_/sia_/smx_` prefixes), the same `--nolibc --exec --batch --mode=exhaustive` oracle flags and the same Lean invocation as `test_exec.sh`, under `scripts/capped` with `CERB_MEM_MAX=48G` and the lane's `TIMEOUT_SECS` (15) unless a flag raises it. Run it at HEAD over the WHOLE corpus (1,669 rows). **Acceptance:** the TSV is committed under `lean_frontend/docs/2026-09-07_fuel-measure-cost-evidence/` (plain text, ≤ 1 MB total for the whole charter); its status column reproduces the lane's classification for every row (cross-check against a `--check-baseline` run: the two known TIMEOUT rows and the 9 baseline TIMEOUT rows, nothing else); the instrument has a `--selftest` or plant (a stub engine with known rusage) and is documented in `scripts/LADDER.md`'s reporting tier as NON-GATING.

(b) Build the pre-arc head `1b57bcf26` whole (oracle + Lean) in `worktrees/cerberus-lean-ref/1b57bcf26` via `scripts/new-worktree.sh cerberus-lean ref/1b57bcf26 1b57bcf26` (the script names the directory `worktrees/<repo>-<branch>`), generating with the lem tool built in-tree from `lem-lean` at `3c88f0d` (`scripts/new-worktree.sh lem-lean ref/3c88f0d 3c88f0d` → `worktrees/lem-lean-ref/3c88f0d`; `make`; prepend its directory to `PATH`), and run D1's instrument there over `small_arrays` (470 rows) and shard `2/6`'s list at least. **Acceptance:** a table `input, cpu_pre, cpu_head, ratio` for every row completing on both; the two rows' ratios; a one-paragraph attribution naming the mechanism in PL terms; a verdict `MEASURES ARE / ARE NOT the dominant cause` with the perf shares quoted.
