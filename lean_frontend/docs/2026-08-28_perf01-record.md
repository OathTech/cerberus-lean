## 3. PERF-1 — the fix pair, as landed

**A. THE PINNED STEP-DISCOVERY (`seg_discover`,
RelSem/SegRoundTac.lean).** Classical names: sharing / explicit
equations (plan L2; in-tree precedent: `advance_action_unfold`'s
"rw with the pinned equation keeps the check linear" note, and the
SegStepper's `mkRflHint` device) + kernel-leaf computation (the
ACL2Lean-pattern ruling: kernel computation for ground side
conditions; the certifying artifact is an ordinary `rfl` the kernel
re-verifies at declaration add — no `ofReduce*`, no transparency
steering, loud fail-closed on every unexpected shape). The tactic
computes the discovery ONCE with `Lean.Kernel.whnf` (8 ms), pins
`find_can_advance (…) = some STEP` as an explicit hinted-rfl
equation, and hands the advance chain a CONCRETE step term — no
unification ever re-derives the discovery. Every round-class tactic
now opens with it.

Effect (measured, same statements, budgets as emitted):
r28 186 s → <2 s; guard 50.6 s → <0.5 s; the full relsem package
build INCLUDING the 88-round chunk A + in-build audit gates:
**~13 min → 42.9 s wall** (commit 987f7905f).

**A'. THE ARM-FORM COMMITTED KEYS (review A4's inventory).** The
dispatch key set, one level below op/verdict — each key = one
tactic, one candidate, values generator-fed off the transcript
diff; an unkeyed form is a loud generation-time error (never
iteration): primitive-conv checked ADD (`seg_round_arith_add_prim
v1 v2` → `p02add_evalR`); literal-first-operand unary minus
(`seg_round_neg_lit`, r257); conv-call arith (the existing

PERF-0 bisect: at literal clamps the post-read remainder is ground

**A''. THE ADAPTIVE COMMITTED PEEL (`seg_peels`).** The peel depth

## 6. Honest limits and residuals

- The kernel-whnf'd step term loses the arena constants' SHARING
  (the kernel expands fragment definitions); downstream defeq
  against constant-spelled successors re-pays a traversal. Measured
  consequence: cheap everywhere except pushing a composite-arena
  Erun through the conv-loop face (probe G2, ≥16M) — routed around
  by the value-form key (the literal-Erun rounds never needed the
  face). A sharing-preserving pin (folding the kernel result back
  onto the named constants) is the clean fix if the class widens.
- `Lean.Kernel.whnf` is marked "mainly for debugging" in core; its
  results are NEVER trusted here — every pinned equation is
  re-verified by the kernel at declaration add (fail-closed; a
  wrong pin is a loud kernel error).
- Blocks carry the `{GF : Iris.BundledGFunctors} [CerbStGS GF]`
  binders, so the supply chunks now import RelSem.SegRun (Iris).
  This keeps the block facts one-application consumables; the
  statement-TCB gate is untouched (supply is proof-layer).
- The A5 ≤5-min closure target is measured in §5 (147.3 s); the
  residual per-round cost is discovery-free content (~0.1–1 s per
  anchor, dominated by the chunk elaboration).
- The mC (a = 0) path needs two explicit rfl spelling bridges in
  the proof text (supply spellings are per-transcript constants;
  the subst path crosses them). A generator that names shared
  sub-arenas canonically would dissolve them — priced follow-up.
- The double-emission safety margin was NOT needed: block-fused
  facts + anchors alone carry all five walks; per-round facts for
  fused instances exist nowhere (the block-granular default is
  real), derivable by hand per the escalation ladder.
