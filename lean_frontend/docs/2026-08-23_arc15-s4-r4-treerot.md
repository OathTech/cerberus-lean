## THE SEQUENCED-CALL RULE (the rung's measured idiom finding)

The first 6-node instance blew a 120s oracle timeout. Bisect: ONE
statement — `*link = rotate_right(*link);` — makes exhaustive mode
enumerate 3 EXECUTIONS (LHS lvalue walk unsequenced with the RHS
call); the factor compounds per site. Fix: land every call result in
a plain local before any member/deref store (`newsub =
rotate_right(*link); *link = newsub;`, and `lch = build_tree(...);
t->left = lch;`). Post-fix: 1 execution, 0.07s. Member stores with
simple-load RHS (`t->left = l->right`) measured FINE — the target C
stays untouched. The S3 harness complied by accident (C99 initializer
style). Register S4-E2; the harness idiom library now carries the
rule.
